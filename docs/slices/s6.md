## What changes in this project

1. **W4 is not their rule.** Their seller threshold has W4's numbers (3 payments, 2 payers), but they use it to count sellers. The report never says it removes volume. W4 removes payments to thin payees, so the README must not call W4 "the Artemis rule". No lifetime row is added: this project has one 7-day window.
2. **Their volume filter cannot be replicated.** The wash and test heuristics are proprietary, so the comparison with this project's waterfall is between published totals, not between methods.
3. **Falsifier 2 compares unlike windows.** 11.05% covers x402 since launch, not only Base, as of 2026-04-21; this project's share is 7 days on Base in October. The pre-registration now cites the PDF's figure, with the band unchanged.
4. **W4 wording.** The PRD said "fewer than 3 payments from fewer than 2 distinct payers", which could be read as "and". It now says "or", as the pre-registration and the report's seller rule do. The code already used "or".
