# Slice 2: attribution and cross-check

**Status.** Run on 2026-10-27. Keyless. `python3 -m ground_truth hour` (hour 2026-10-25 14:00 UTC, blocks 53,073,727 to 53,075,526). Rows in `out/s2/`.

## What it adds

- `ground_truth/settlements.py`: rule W1 as a pure function on one facilitator-sent receipt. It returns the W0 transfers, the payments and every removed transfer with a reason: `second_hop`, `channel_movement` or `non_payment`.
- Schemes: EIP-3009, the exact and upto Permit2 proxies (`Settled` / `SettledWithPermit`), and batch-settlement claims.
- `ground_truth/channels.py`: batch channel payer and receiver from `ChannelCreated`, walking back at most 2M blocks.
- `ground_truth/coverage.py`: a full-block scan for facilitator-sent transactions, and a facilitator nonce count at the range edges.
- `ground_truth/rpc.py`: one retry loop (5 tries with backoff), exit code 3 on failure, and labels naming the failing call. A cached request is never sent again.
- `docs/preregistration.md`: falsifiers and rule thresholds, committed before the 7-day census.

## What slice 2 found that changes later slices

1. **The rolling 7-day total has an unknown start.** x402scan computes it in a materialized view over `NOW() - 7 days` at an unpublished refresh time. Its bucketed series uses exact 3.5-hour buckets, so slice 3 uses the 47 complete buckets from 2026-10-20 18:00 to 2026-10-27 14:30 UTC and compares bucket by bucket (PRD change log).
2. **Batch claims sit outside W0.** All 18 `Claimed` events in the hour were sent by addresses that are not listed facilitators, so neither x402scan's filter nor W0 counts them. The 1 claimed channel was not found within 2M blocks. Slice 3 reports claim volume as its own line next to the waterfall.
3. **The keyless node's limits.** `eth_getLogs` is capped at 50,000 blocks, old state returns 403, and logs 2M blocks back are still served (source O4).
